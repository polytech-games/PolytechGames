# Разработка «Жана на грани»

Игрок открывает `index.html`; установка и сборка ему не нужны.

Исходный авторский проект не входил в репозиторий. Код здесь восстановлен из поставленного HTML: форматирование, граница между движком и игрой и имена файлов изображений восстановлены, исходные имена переменных и исходная структура модулей — нет. Авторство игры сохранено. Движок не обновлялся. Звук синтезируется через Web Audio, как и при отсутствии звуковых файлов в исходной версии; запросы к отсутствующим MP3/OGG удалены.

- `src/game.js` — данные изображений, конфигурация, диалоги, сцены, мини-игры, меню и игровой цикл. Разделы отмечены комментариями.
- `src/vendor/pixi.js` — движок из исходной сборки, отдельно от игровой логики.
- `src/style.css` — стили интерфейса.
- `src/page.html` — HTML-шаблон с маркерами `GAME_STYLE` и `GAME_SCRIPT`.
- `assets/` — изображения с именами из игрового манифеста (`jan_desk_idle.webp`, `bg_title.webp` и т. д.). Маленькие встроенные изображения проверки поддержки кодеков остались в движке.
- `tools/build.py` — сборщик без сторонних Python-пакетов и npm.

После изменения исходников:

```bash
python3 games/zhan-na-grani/tools/build.py
```

Сборщик создаёт два файла:

- `index.html` — автономный HTML со встроенными стилями, скриптами и изображениями;
- `dev.html` — тот же код с отдельными стилями и изображениями для проверки путей и ресурсов.

Оба файла открываются через `file://` и HTTP. Скрипт использует обычный JavaScript с общей замкнутой областью видимости для движка и игры; сервер для ES-модулей не требуется. Шрифты Google необязательны: при отсутствии сети используются системные.

Для проверки актуальности сборки без перезаписи:

```bash
python3 games/zhan-na-grani/tools/build.py --check
```

Коммить исходники вместе с обновлёнными `index.html` и `dev.html`. Общие команды проверок находятся в корневом README.
