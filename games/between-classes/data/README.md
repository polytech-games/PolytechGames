# Недельное расписание

`schedule.json` — расписание П-24-67Б, I семестр, перенесённое с изображения `references/weekly-timetable.png`: 18 пар с понедельника по пятницу.

- `days[].lessons[]`: номер пары `slot` и ссылки на справочники `courses`, `teachers`, `rooms`.
- `timeSlots`: номера пар 1–6. `start` и `end` пока `null`: время звонков не было указано.
- `roomId: null`: аудитория неизвестна. Это третья пара среды; аудитория четверга автоматически не подставляется.
- `rooms[].buildingSource`: `user-confirmed` для 1406 и 3213, `inferred-from-room-prefix` для остальных цифровых аудиторий. Корпус спортзала неизвестен.
- `courses[].title`: название предмета из расписания. `gameplayTopic`: тема игровой сцены; у Стасиншиной — HTML-вёрстка по уточнению пользователя.
- `courses[].lessonId`: связь с готовой микроновеллой в `campus-data.js`, либо `null`, если сцена ещё не написана.

Пропуски в нумерации сохранены: вторник начинается со второй пары, четверг — с четвёртой. Год и времена не выдуманы. Написание фамилии Стасиншиной нормализовано по сообщению пользователя.

Сейчас это справочник данных. Ограничение входов по времени, выбор дня недели и автоматическое начало следующей пары ещё не подключены. JSON не загружается через `fetch`, поэтому текущий запуск через `file://` от него не зависит.
