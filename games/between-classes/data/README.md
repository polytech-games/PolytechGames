# Недельное расписание

`schedule.json` — основной источник расписания П-24-67Б, I семестр: 18 пар с понедельника по пятницу из `references/weekly-timetable.png`. Все шесть звонков перенесены из `references/bell-times.png`.

- `days[].lessons[]`: номер пары `slot` и ссылки на справочники `courses`, `teachers`, `rooms`.
- `timeSlots`: пары 1–6 с `start` и `end` в формате `HH:MM`.
- `roomId: null`: аудитория неизвестна (третья пара среды).
- `rooms[].buildingSource`: подтверждённые пользователем корпуса для 1406 и 3213; остальные цифровые аудитории предполагают корпус по первой цифре. Корпус спортзала неизвестен.
- `courses[].title`: название из расписания; `gameplayTopic`: игровая тема (у Стасиншиной — HTML-вёрстка); `lessonId`: связь со сценой в `campus-data.js` либо `null`.

Пропуски номеров пар сохранены. Фамилия Стасиншиной нормализована по сообщению пользователя. Год не задан.

`schedule.browser.js` генерируется из JSON для запуска без `fetch`, в том числе через `file://`. После изменения JSON из корня репозитория выполнить:

```sh
node games/between-classes/tools/build-schedule.cjs
node games/between-classes/tools/build-schedule.cjs --check
```

Проверка сравнивает файл целиком и завершается с ошибкой при расхождении. Она также включена в `tests/between-classes-day.test.cjs`.

В игре доступны все четыре пары пятницы, все четыре пары вторника и системная безопасность в четверг (пара 4, аудитория 1404). Третья пара среды с Муратовым остаётся в расписании без указанной аудитории. `day.js.createModel(dayId)` создаёт отдельную модель дня.
