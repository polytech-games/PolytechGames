# 🤝 Руководство по внесению вклада (CONTRIBUTING.md)

Привет, студент политеха! Если ты сделал свою браузерную игру и хочешь добавить её в этот легендарный бекап студенческих игр — мы с радостью ждём твой **Pull Request (PR)**!

---

## 🎯 Основные критерии приёма игр

Чтобы твой PR был принят и влит в репозиторий, игра должна строго соответствовать следующим правилам:

1. 🎓 **Авторство:**
   * Автор(ы) игры **обязаны быть студентами группы П-24-67Б** (Высший колледж «Astana Polytechnic»).
   * В начале HTML-файла или в описании PR обязательно укажи своё ФИО и никнейм на GitHub.

2. 🏫 **Тематика игры:**
   * Игра **должна быть посвящена учёбе, будням и атмосфере в колледже** (пары, преподаватели, домашки, столовая, сессия, опоздания, физра и т.д.). Творческий юмор и мемность приветствуются!

3. 🌐 **Формат и стек:**
   * **Один файл (Single-file HTML):** игра должна быть полностью упакована в единый `.html`-файл (включая стили `<style>` и логику `<script>`).
   * Игра должна запускаться простым двойным кликом в браузере без установки `npm`, сторонних серверов и сборщиков.
   * Никакого вредоносного кода, фишинга или скриптов-майнеров.

## 🚀 Пошаговая инструкция: как отправить Pull Request

### 1. Форкните репозиторий
Нажмите кнопку **Fork** в правом верхнем углу репозитория [skippingclass/PolytechGamesBackup](https://github.com/skippingclass/PolytechGamesBackup).

### 2. Клонируйте свой форк на компьютер
```bash
git clone https://github.com/<твой-никнейм>/PolytechGamesBackup.git
cd PolytechGamesBackup
```

### 3. Создайте новую ветку для своей игры
```bash
git checkout -b feature/название-твоей-игры
```

### 4. Добавьте файл с игрой
* Положите свой `.html`-файл в корень репозитория (например: `ekzamen-simulator.html`).
* Сделайте скриншот титульного экрана или геймплея и добавьте его в папку `screenshots/` (в формате `.png`).

### 5. Обновите `README.md`
Добавьте свою игру в:
1. Таблицу авторов раздела **«Авторы и разработчики»** (ФИО, группа **П-24-67Б**, ссылка на GitHub).
2. Раздел **«Обзор игр»**: название, скриншот, краткое описание сюжета и управление.

### 6. Закоммитьте и запушьте изменения
```bash
git add .
git commit -m "feat: добавлена игра <Название игры> от студента группы П-24-67Б"
git push origin feature/название-твоей-игры
```

### 7. Откройте Pull Request
1. Перейдите на страницу оригинального репозитория [skippingclass/PolytechGamesBackup](https://github.com/skippingclass/PolytechGamesBackup).
2. Нажмите **Compare & pull request**.
3. В описании PR укажите:
   * **Название игры**
   * **Автор(ы):** ФИО, группа (подтверждение, что вы из **П-24-67Б**)
   * **О чём игра** (краткий синопсис)
4. Отправьте PR и ждите ревью от [@skippingclass](https://github.com/skippingclass) или [@AKDWorks](https://github.com/AKDWorks)!
